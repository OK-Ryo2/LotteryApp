# LotteryApp UI設計

## 画面サイズ

1920 × 1080

## レイアウト

- 左：賞品一覧
- 中央：現在の賞品・抽選者表示・抽選ボタン
- 右：当選履歴
- 右上：参加人数
- 左下：音量ボタン
- 右下：設定ボタン

## 画面を構成する部品

- Header（タイトル）
- PrizeList（賞品一覧）
- CurrentPrize（現在の賞品）
- WinnerDisplay（当選者表示）
- Roulette（ルーレット表示）
- HistoryList（当選履歴）
- ParticipantCount（参加人数）
- ControlButtons（抽選開始・設定・音量）


## PrizeCard（賞品カード）

賞品一覧はリスト形式ではなく、カード形式で表示する。

1枚のカードに表示する内容

- 等級（20等、19等…）
- 賞品名
- 残り当選人数

状態

- 未公開（賞品名を？？？表示）
- 公開
- 抽選中
- 抽選終了
