# LotteryApp

忘年会などのイベントで使う、参加者名シャッフル抽選アプリです。参加者CSVを読み込み、画面中央のルーレットを開始・停止して当選者を決定します。

> 現在は開発途中のバージョンです。賞品一覧・現在の賞品・当選履歴は表示の土台まで実装済みで、賞品データの切替や履歴表示は今後追加します。

## できること

- `department,name` 形式のCSVから参加者を読み込む
- ルーレットに参加者名と部署名を表示する（初回の扇形カード配置は参加者CSVの行順ではなくランダム）
- 「抽選スタート」「ストップ」で当選者を決定する
- 一度当選した参加者を、その起動中の次回以降の抽選候補から除外する
- 参加人数を画面右上に表示する
- 直近6件の当選履歴を表示する
- 賞品が切り替わると、抽選中の賞品カードが左の一覧内に収まる位置まで自動スクロールする
- 複数個ある賞品の途中では、操作ボタンを「次の抽選へ」と表示し、同じ賞品の次回抽選を準備する
- 「次の賞品へ」は現在の景品を引き終えた場合に表示し、押すと次の等級へ進む
- 次の操作ボタンは押下後に非活性となり、次の当選者を確定するまで再度押せない
- 画面サイズや表示倍率に応じて、ヘッダー・文字サイズ・中央パネルの各エリアを自動調整する
- 当選者はルーレット停止後にポップアップで表示する
- 画面下部の音量ボタンでON/OFF表示を切り替え、設定ボタンで設定ポップアップを開く

## 起動前の準備

### 1. 必要なソフト

Windows PCに以下を用意してください。

- Python 3.13
- PowerShell

初回のみ、プロジェクトフォルダで仮想環境と必要なライブラリを準備します。PowerShellを開き、次を実行してください。

```powershell
cd C:\Develop\LotteryApp
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

すでに `.venv` フォルダがある場合は、最後のライブラリインストールだけで構いません。

### 2. 参加者CSVを準備する

参加者ファイルは [data/participants.csv](data/participants.csv) に配置します。Excelで編集する場合は、**CSV（コンマ区切り・Shift_JIS/CP932）** で保存してください。

`data/participants.csv` と `data/prizes.csv` は抽選開始に必須です。初期画面の「商品の紹介へ」を押した時点で不足しているCSVがある場合、警告を表示して賞品紹介・抽選を開始しません。両方不足している場合は、両方の警告をまとめて表示します。

CSVは必ず次の2列だけを、左からこの順番で記載します。

```csv
department,name
ICA1,山田 太郎
ICA2,佐藤 花子
air(ICA1),鈴木 一郎
```

ルールは次のとおりです。

- 1行目は必ず `department,name` とする
- 部署と氏名はどちらも必須
- 部署名・氏名の前後に余分な空白を入れない
- CSVをExcelで開いている場合は、アプリ起動前にExcelを閉じる

リポジトリには、個人情報を含まない架空のサンプル50名を登録しています。本番運用時は、必ず実際の参加者CSVへ差し替えてください。本番CSVをGitへコミットしたり、外部へ共有したりしないでください。

### 3. 景品JSONを確認・編集する

景品一覧は [data/prizes.json](data/prizes.json) にまとめて管理しています。1つの景品を1つのオブジェクトとして記載した、整形済みのJSON配列です。

```json
{
  "id": "prize-01",
  "rank": 1,
  "list_name": "一覧表示用の景品名",
  "current_name": "中央表示用の景品名",
  "image_path": "assets/images/prizes/example.png",
  "stock": 1
}
```

- `id`：景品を一意に識別する不変のID。既存のIDは変更しないでください。
- `rank`：等級を表す数値。画面では自動的に「等」を付けて表示します。
- `list_name`：左側の賞品一覧に表示する景品名。
- `current_name`：中央の現在賞品に表示する景品名。
- `description`：賞品公開ポップアップに表示する商品説明。
- `image_path`：プロジェクトフォルダから見た画像PNGへの相対パス。
- `stock`：その景品の個数。1以上の整数を指定します。

JSONは直接編集できます。`id`の重複、`rank`の重複、空の項目、不正な個数があると起動時にエラーになります。変更後はアプリを再起動してください。

#### CSVから自動変換する場合

[data/prizes.csv](data/prizes.csv) に、次の日本語見出しで景品を記載できます。

```csv
賞品ID,等級,賞品名(一覧表示),賞品名(中央表示),商品説明,画像ファイルパス,個数
prize-01,1,一覧表示用の景品名,中央表示用の景品名,賞品の説明文です,assets/images/prizes/example.png,1
```

アプリ起動時、CSVがJSONより新しい場合は自動で `prizes.json` へ変換されてから画面表示されます。CSVはWindows版Excelで文字化けしない **Shift_JIS（CP932）のCSV（コンマ区切り）** で保存し、Excelを閉じてからアプリを起動してください。

`商品説明`列は任意です。従来どおり6列（商品説明なし）のCSVでも読み込め、賞品名を使った既定の説明文をポップアップに表示します。

JSONを直接編集して運用する場合は、CSVを変更しなければJSONの内容が維持されます。CSVを再編集・保存した次回起動時に、そのCSV内容でJSONが更新されます。

## アプリの起動

PowerShellで次を実行します。

```powershell
cd C:\Develop\LotteryApp
.\.venv\Scripts\python.exe src\main.py
```

起動すると、参加者CSVが自動で読み込まれます。画面右上の「参加人数」がCSVの人数と一致していることを確認してください。

## 抽選の手順

1. 起動直後はルーレット領域にタイトル画像が表示されます。初期画面の「商品の紹介へ」を押すと、最下位（20等）から賞品紹介ポップアップが開きます。
2. 賞品を確認して「この賞品で抽選開始」を押します。対象の賞品だけ一覧で公開され、ルーレット表示へ切り替わります。
3. 表示された「🎉 抽選スタート」を押し、ルーレットの候補者表示が切り替わることを確認します。
4. 決定したいタイミングで「🎉 ストップ」を押します。ホイールが減速して停止します。
5. 当選者ポップアップを閉じると、当選履歴へ結果が追加されます。同じ賞品が残っている場合は「次の抽選へ」を押して同じ賞品の抽選を続けます。引き終えた場合は「次の賞品へ」を押すと、次の景品の紹介ポップアップを表示します。

当選者は、そのアプリを起動している間は抽選候補から自動的に除外され、画面右上の参加人数も1名減ります。「次の抽選へ」または「次の賞品へ」を押すと、残っている候補の中からランダムな位置でルーレット表示を再開します。停止後は次の操作ボタンを押すまで開始ボタンが無効になるため、同じ当選者を続けて確定することはありません。

景品は20等から1等の順に抽選します。同じ等級の景品が複数ある場合は、残数が0になるまでその景品を続けて抽選し、すべて引き終えた時点で次の等級へ切り替わります。
景品の残数は「ストップ」時ではなく、「次の賞品へ」を押した時点で減ります。残数が0になる景品はそのまま次の等級へ切り替わるため、画面上に「残り0名」は表示されません。

当選履歴には、等級・賞品名・当選者名・当選時刻（`HH:MM`）を表示します。履歴は直近6件だけ保持し、7件目以降の古い履歴は破棄されます。

参加者全員が当選すると、「全員当選しました」と表示され、抽選操作はできなくなります。

## 運用時の注意

- 当選者の除外状態は、現在はアプリを閉じるとリセットされます。途中再開が必要な場合は、アプリを閉じずに運用してください。
- 参加者CSVを変更した場合は、アプリを一度終了してから再起動してください。CSVの再読込ボタンは未実装です。
- 賞品一覧は未公開の賞品をマスクして表示します。紹介ポップアップで抽選開始を確定した賞品だけ、画像と名称が公開されます。
- 会場で使用する前に、必ずサンプルCSVで起動・開始・停止・次の抽選を一度確認してください。

## 終了方法

ウィンドウ右上の `×` を押して終了します。

## ルーレットの操作

- 抽選開始ボタンを押すと、参加者CSVの氏名を扇形ホイール上で回転表示します。氏名の下には同じCSVの部署名を表示します。
- 開始後の加速演出中（約2秒間）は「ストップ」ボタンが非活性になり、最高速に達した後に操作できます。
- 回転中に同じボタン（「ストップ」表示）を押すと、ホイールは慣性を残して徐々に減速し、上部のポインター位置で停止してから当選者を確定します。
- 当選者は以降の抽選候補から自動的に除外されます。参加者CSVの列構成は従来どおり `department,name` のままです。

## 賞品の公開

- 起動直後の賞品一覧は、画像・賞品名・状態をマスクして表示します。
- 「次の賞品へ」を押すと、次に抽選する賞品の等級・名称・画像・商品説明を紹介するポップアップが表示されます。
- ポップアップ内の「この賞品で抽選開始」を押すと、その賞品だけ一覧で公開され、抽選を開始できます。
- 賞品一覧の個数は常に景品ごとの合計数を `x名様` として表示します。中央の現在賞品には、当選履歴へ反映済みの件数と合計個数を `x(残り個数)/y(合計個数)　抽選済み` の形式で表示します。

## 設定メニュー

- 設定ポップアップの「ソースを再読み込み」を使うと、確認後に現在のアプリを自動再起動し、修正したPythonソースを反映できます。手動でウィンドウを閉じてコマンドを再実行する必要はありません。再起動時に抽選状態は初期化されます。
- 画面右下の「設定」から「抽選初期化」を選ぶと、当選履歴・参加者の当選状態・賞品残数・賞品公開状態を起動直後の状態へ戻せます。
- 「賞品再抽選」を選ぶと、最後に紹介した賞品を紹介・抽選前の状態へ戻せます。再度「次の賞品へ」から紹介して抽選できます。
- どちらも確認画面で「Yes」を選んだ場合だけ実行され、「No」を選んだ場合は変更されません。

## 音量と抽選演出音

- 参加者カードの切り替わり時に短い音を再生します。
- 当選カードの点滅中は短い音を繰り返し再生します。
- 当選者ポップアップ表示時にファンファーレを再生します。
- 音量をONに切り替えるとテスト音を1回再生します。
- 音量をOFFにすると、上記を含むすべての効果音を停止します。
- 音源は`assets/sounds/`に配置しています。過去版の音源は`assets/sounds/old/`に退避します。

## 画像ファイルの配置

- `assets/images/prizes/`：景品画像
- `assets/images/ui/`：画面UI画像（タイトル、翼、リボン、ロック画像など）
- `assets/images/ui/ranks/`：賞品一覧の等級背景画像
- `assets/images/icons/`：参加人数などのアイコン
- `assets/images/effects/`：紙吹雪などの演出画像
- `assets/images/backgrounds/`：アプリ全体の背景画像
